# Complete Workflow Guide - Running All Agents

This guide shows how to run the complete pipeline from dataset analysis to improved model validation code.

## Prerequisites

1. **Python 3.10+** installed
2. **Ollama** running with a model (e.g., `phi4` or `llama3`)
   ```powershell
   # Start Ollama (if not running)
   ollama serve
   
   # Pull a model (if not already pulled)
   ollama pull phi4
   # or
   ollama pull llama3
   ```
3. **Install dependencies** for each agent:
   ```powershell
   # Pre Processing Agent
   cd "Pre Processing Agent"
   pip install -r requirements.txt
   cd ..
   
   # Reasoning Agent
   cd "Reasoning Agent"
   pip install -r requirements.txt
   cd ..
   
   # Improvement Agent (optional)
   cd "Improvement Agent"
   pip install -r requirements.txt
   cd ..
   ```

## Complete Workflow

### Step 1: Pre Processing Agent - Generate Dataset Report

**Purpose**: Analyze dataset and generate a JSON report with dataset characteristics.

**Location**: `Pre Processing Agent/` folder

**Command**:
```powershell
cd "Pre Processing Agent"

# Run the workflow agent
python preprocessing_workflow_agent.py

# Or use report_generator directly
python report_generator.py --csv "../Datasets/Housing.csv" --target "price" --output "../Housing.json"
```

**Output**: 
- `{DatasetName}.json` - Dataset analysis report (e.g., `Housing.json`, `AAPL.json`)
- `{DatasetName}_preprocessing_plan.json` - Preprocessing plan
- `{DatasetName}_preprocessing_code.py` - Generated preprocessing code

**Example for Housing dataset**:
```powershell
cd "Pre Processing Agent"
python report_generator.py --csv "../Datasets/Housing.csv" --target "price" --output "../Housing.json"
```

**Example for AAPL dataset**:
```powershell
cd "Pre Processing Agent"
python report_generator.py --csv "../Datasets/AAPL.csv" --target "Day" --output "../AAPL.json"
```

---

### Step 2: Reasoning Agent - Train Models (Uses Pre Processing Report Directly)

**Purpose**: Get model recommendations and generate validation code using the Pre Processing Agent report.

**Location**: `Reasoning Agent/` folder

**Note**: The Reasoning Agent now uses the Pre Processing Agent report directly - no need to generate separate metadata! It automatically converts the report to the required format.

#### 2.1 Train Models (Complete Pipeline)

This command does everything:
- Converts Pre Processing Agent report to metadata format
- Gets model recommendations from LLM
- Prompts you to select 1-3 models interactively
- Generates Python validation code for selected models
- Executes and evaluates models

```powershell
cd "Reasoning Agent"

python -m src.main train-models "../Housing.json" "../Datasets/Housing.csv" ^
  --context "Housing price prediction with feature engineering" ^
  --test-size 0.2 ^
  --min-models 1 ^
  --max-models 3 ^
  --code-dir generated_code
```

**Output**:
- `generated_code/{DatasetName}_validate_models.py` - Validation code (e.g., `Housing_validate_models.py`)
- `generated_code/{DatasetName}_deploy_best_model.py` - Deployment code for best model
- Evaluation metrics displayed in console

**Example for Housing dataset**:
```powershell
cd "Reasoning Agent"
python -m src.main train-models "../housing report.json" "../Datasets/Housing.csv" ^
  --context "Regression problem for house price prediction" ^
  --test-size 0.2
```

**Example for AAPL dataset**:
```powershell
cd "Reasoning Agent"
python -m src.main train-models "../AAPL.json" "../Datasets/AAPL.csv" ^
  --context "Stock price classification" ^
  --test-size 0.2
```
**Example for housing dataset**:
cd "Reasoning Agent"
python -m src.main train-models "../housing report.json" "../Datasets/Housing.csv" ^
  --context "Real estate price prediction. Need interpretable models for business stakeholders. Small dataset with skewed target distribution." ^
  --test-size 0.2

**Note**: The first argument is now the Pre Processing Agent report file (e.g., `Housing.json` or `housing report.json`), not a metadata file! The report is automatically converted to metadata format internally.

---

### Step 3: Improvement Agent - Enhance Generated Code (Optional)

**Purpose**: Improve the validation code generated by Reasoning Agent using ML best practices.

**Location**: `Improvement Agent/` folder

**Note**: The Improvement Agent analyzes the dataset report and the generated validation code to create an improved version.

**Manual Process** (Currently):
1. Copy the generated validation code from `Reasoning Agent/generated_code/{DatasetName}_validate_models.py`
2. Copy the dataset report from `{DatasetName}.json` (in project root or Pre Processing Agent folder)
3. Review the improved code in `Improvement Agent/improved_validate_models.py` or `optimized_validate_models.py`

**Files in Improvement Agent**:
- `improved_validate_models.py` - Comprehensive improvements (for Housing dataset)
- `optimized_validate_models.py` - Code quality optimizations (for AAPL dataset)
- `optimization_report.json` - Details of optimizations applied

## File Naming Convention

All generated files are now named after the dataset:

| Dataset | Report | Validation Code | Deployment Code |
|---------|--------|-----------------|-----------------|
| Housing.csv | Housing.json | Housing_validate_models.py | Housing_deploy_best_model.py |
| AAPL.csv | AAPL.json | AAPL_validate_models.py | AAPL_deploy_best_model.py |

**Note**: The Reasoning Agent now uses the Pre Processing Agent report directly - no separate metadata file needed!

## Troubleshooting

### Ollama Not Running
```powershell
# Start Ollama server
ollama serve

# In another terminal, verify it's running
ollama list
```

### Missing Dependencies
```powershell
# Install for each agent
cd "Pre Processing Agent" && pip install -r requirements.txt && cd ..
cd "Reasoning Agent" && pip install -r requirements.txt && cd ..
cd "Improvement Agent" && pip install -r requirements.txt && cd ..
```

### File Not Found Errors
- Make sure you're in the correct directory when running commands
- Use relative paths from the project root: `../Datasets/Housing.csv`
- Check that dataset files exist in the `Datasets/` folder

### Model Not Found
```powershell
# Pull required model
ollama pull phi4
# or
ollama pull llama3
```

## Key Commands Reference

```powershell
# Pre Processing Agent
cd "Pre Processing Agent"
python report_generator.py --csv "../Datasets/{Dataset}.csv" --target "{target_column}" --output "../{Dataset}.json"

# Reasoning Agent - Train Models (uses report directly)
cd "Reasoning Agent"
python -m src.main train-models "../{Dataset}.json" "../Datasets/{Dataset}.csv" --test-size 0.2
```

Replace `{Dataset}` with your dataset name (e.g., `Housing`, `AAPL`) and `{target_column}` with your target column name.
